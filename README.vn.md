## 🧭 Đây là gì?

Repository này là một **kho kiến thức có cấu trúc**, ghi chép nghiên cứu về **Agentic Coding** — phương pháp điều phối AI agents để xây dựng phần mềm một cách có hệ thống, vượt ra ngoài "code bằng chat" đơn giản (Vibe Coding) hướng tới **phát triển đa agent, đáng tin cậy, dựa trên spec**.

Mỗi chủ đề được tài liệu hóa theo **cấu trúc 4 tài liệu** nhất quán:

| # | Tài liệu | Mục đích |
|:--|:---------|:---------|
| 0 | **Tổng quan (Overview)** | Đây là gì, vấn đề giải quyết, triết lý thiết kế |
| 1 | **Kiến trúc & Logic** | Kiến trúc nội bộ, luồng dữ liệu, cơ chế cốt lõi |
| 2 | **Playbook** | Hướng dẫn thực hành — cài đặt, vận hành, cheat sheet, xử lý sự cố |
| 3 | **Hướng dẫn Ra quyết định** | So sánh với alternatives, use cases, chi phí, migration path |
