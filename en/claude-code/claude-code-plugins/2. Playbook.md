# Claude Code Plugins — Playbook

## Part I: Installing Plugins

### 1.1. From Official Anthropic Marketplace

```bash
# Install directly (official marketplace is built-in)
/plugin install superpowers@claude-plugins-official
/plugin install typescript-lsp@claude-plugins-official
```

### 1.2. From Custom Marketplace

```bash
# Step 1: Add marketplace
/plugin marketplace add owner/marketplace-repo

# Step 2: List available plugins
/plugin marketplace list

# Step 3: Install plugin
/plugin install plugin-name@marketplace-name
```

### 1.3. From Local Directory (Development)

```bash
# Load plugin from local dir for testing
claude --plugin-dir ./my-plugin

# Or add as local plugin
/plugin install --path ./my-plugin
```

### 1.4. Verify Installation

```bash
# List installed plugins
/plugin list

# Check specific plugin
/plugin info plugin-name
```

## Part II: Creating Your First Plugin

### 2.1. Minimal Plugin

```bash
mkdir my-plugin
cd my-plugin

# Create manifest
mkdir -p .claude-plugin
cat > .claude-plugin/plugin.json << 'EOF'
{
  "name": "my-plugin",
  "version": "1.0.0",
  "description": "My first Claude Code plugin"
}
EOF

# Create a skill
mkdir -p skills/hello
cat > skills/hello/SKILL.md << 'EOF'
---
name: hello
description: Use when greeting the user
---

# Hello Skill

Always respond with a friendly greeting in the user's language.
EOF
```

### 2.2. Test Locally

```bash
claude --plugin-dir ./my-plugin
# Then try: /my-plugin:hello
```

### 2.3. Add More Components

#### Add an Agent

```bash
mkdir -p agents
cat > agents/code-reviewer.md << 'EOF'
You are a code reviewer. Review code for:
- Security issues
- Performance problems
- Code style violations
- Missing tests
EOF
```

#### Add Hooks

```bash
mkdir -p hooks
cat > hooks/hooks.json << 'EOF'
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "echo 'File changed via plugin hook'"
          }
        ]
      }
    ]
  }
}
EOF
```

## Part III: Marketplace Distribution

### 3.1. Create a Marketplace

```bash
# Create marketplace repo
mkdir my-marketplace
cd my-marketplace

cat > marketplace.json << 'EOF'
{
  "name": "My Team Marketplace",
  "description": "Internal team plugins",
  "plugins": [
    {
      "name": "my-plugin",
      "description": "My awesome plugin",
      "git": "https://github.com/user/my-plugin.git",
      "ref": "v1.0.0"
    }
  ]
}
EOF

git init && git add . && git commit -m "Initial marketplace"
git remote add origin https://github.com/user/my-marketplace.git
git push -u origin main
```

### 3.2. Team Usage

```json
// .claude/settings.json (committed to project repo)
{
  "extraKnownMarketplaces": [
    "my-team/claude-plugins-marketplace"
  ]
}
```

Team members can then:
```bash
/plugin install my-plugin@my-team-marketplace
```

### 3.3. Submit to Official Marketplace

Submit via:
- `claude.ai/settings/plugins/submit`
- `platform.claude.com/plugins/submit`

## Part IV: Migrating Configurations

### From `.claude/` to Plugin

```bash
# If you have skills in .claude/skills/
# Move to plugin structure:

mkdir -p my-plugin/.claude-plugin
echo '{"name": "my-config"}' > my-plugin/.claude-plugin/plugin.json

# Move skills
mv .claude/skills/ my-plugin/skills/

# Move agents
mv .claude/agents/ my-plugin/agents/

# Move hooks
mv .claude/hooks/ my-plugin/hooks/
```

## Part V: Plugin Management

### Daily Operations

```bash
# List all installed plugins
/plugin list

# Get plugin info
/plugin info plugin-name

# Update a plugin
/plugin update plugin-name

# Update all plugins
/plugin update --all

# Disable (keep installed but inactive)
/plugin disable plugin-name

# Enable
/plugin enable plugin-name

# Uninstall
/plugin uninstall plugin-name

# Reload after edits (no restart needed)
/reload-plugins
```

## Part VI: Cheat Sheet

### Plugin Commands

| Command | Description |
|---|---|
| `/plugin install name@marketplace` | Install plugin |
| `/plugin install --path ./dir` | Install from local path |
| `/plugin list` | List installed plugins |
| `/plugin info name` | Show plugin details |
| `/plugin update name` | Update specific plugin |
| `/plugin update --all` | Update all plugins |
| `/plugin enable name` | Enable disabled plugin |
| `/plugin disable name` | Disable plugin |
| `/plugin uninstall name` | Remove plugin |
| `/plugin marketplace add owner/repo` | Add marketplace |
| `/plugin marketplace list` | List marketplaces and their plugins |
| `/plugin marketplace remove name` | Remove marketplace |
| `/reload-plugins` | Hot-reload all plugins |

### Plugin Structure

```
my-plugin/
├── .claude-plugin/
│   └── plugin.json         # Manifest (required)
├── skills/                  # Auto-discovered skills
│   └── skill-name/
│       └── SKILL.md
├── agents/                  # Auto-discovered agents
│   └── agent-name.md
├── commands/                # Legacy slash commands
│   └── command-name.md
├── hooks/                   # Event hooks
│   └── hooks.json
├── .mcp.json                # MCP server config
├── .lsp.json                # LSP server config
└── settings.json            # Default settings
```

### Installation Scopes

| Scope | Config Location | Committed? | Use Case |
|---|---|---|---|
| User | `~/.claude/settings.json` | No | Personal plugins |
| Project | `.claude/settings.json` | Yes | Team plugins |
| Local | `.claude/settings.local.json` | No | Personal overrides |
| Managed | System-level | N/A | Enterprise |

## Part VII: Troubleshooting

### Plugin Not Found

| Cause | Fix |
|---|---|
| Marketplace not added | `/plugin marketplace add owner/repo` |
| Plugin name typo | Check `/plugin marketplace list` |
| Network issue | Check internet connection |

### Skills Not Loading

| Cause | Fix |
|---|---|
| Missing SKILL.md | Ensure `skills/<name>/SKILL.md` exists |
| Wrong directory structure | Follow convention exactly |
| Plugin disabled | `/plugin enable name` |
| Cache stale | `/reload-plugins` or `/plugin update` |

### Hooks Not Firing

| Cause | Fix |
|---|---|
| Invalid hooks.json | Validate JSON syntax |
| Wrong matcher | Check tool names in matcher |
| Plugin disabled | `/plugin enable name` |

### LSP Not Working

| Cause | Fix |
|---|---|
| Language server not installed | Install the server binary (e.g., `npm i -g typescript-language-server`) |
| Wrong language mapping | Check `.lsp.json` languages field |
| Server crash | Check server logs |
