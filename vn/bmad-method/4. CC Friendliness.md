## Highlight

> BMad Method **tiến bộ đáng kể từ 6.0 → 6.2** nhờ skills-based architecture (tuân thủ Agent Skills open standard), step-file sharding, và progressive disclosure. Tuy nhiên **kiến trúc vẫn HITL-heavy** — hầu hết tasks yêu cầu human interaction liên tục → khó delegate cho Claude Code subagents. **Product Brief Preview** (v6.2) là skill đầu tiên thử nghiệm autonomous mode với subagent fan-out — nếu pattern này được áp dụng rộng, CC Friendliness sẽ tăng đáng kể.

## Recommendations để tăng CC score

| Recommendation | Impact | Difficulty |
|---|---|---|
| Thêm autonomous/HOTL mode cho thêm nhiều workflows (như Product Brief Preview) | +3-5 Agentic | Medium |
| Dùng `.claude/rules/` thay vì inject vào context | +2 Memory | Low |
| Thêm MCP server cho skill discovery/invocation | +2 Extensions | High |
| Model routing: dùng nhẹ cho validation, nặng cho creation | +2 Cost | Medium |
| Technical permission rules (CLAUDE.md deny patterns) | +2 Safety | Low |
