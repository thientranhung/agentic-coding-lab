# Claude Code Plugins — Playbook

## 1. Cài đặt & Thiết lập

### Prerequisites

| Yêu cầu | Lệnh kiểm tra | Ghi chú |
|---|---|---|
| Claude Code ≥ 1.0.33 | `claude --version` | Plugin cần version này trở lên |
| Claude Code authenticated | — | Đã login, có API key |

### Cập nhật Claude Code (nếu cần)

```bash
# Homebrew
brew upgrade claude-code

# npm  
npm update -g @anthropic-ai/claude-code

# Native installer — chạy lại install command từ docs
```

### Thêm Official Marketplace

```bash
# Trong Claude Code session:
/plugin marketplace add anthropics/claude-code
```

### Cài Plugin từ Marketplace

```bash
# Cú pháp chung
/plugin install <plugin-name>@<marketplace-name>

# Ví dụ thực tế — cài TypeScript LSP
/plugin install typescript-lsp@claude-plugins-official

# Cài với scope cụ thể
/plugin install formatter@my-marketplace --scope project    # Shared với team
/plugin install formatter@my-marketplace --scope local      # Chỉ cá nhân, gitignored
/plugin install formatter@my-marketplace --scope user       # Default: global
```

## 2. Day 1 — Tạo Plugin đầu tiên

### Bước 1: Tạo cấu trúc plugin

```bash
mkdir my-first-plugin
mkdir my-first-plugin/.claude-plugin
```

### Bước 2: Tạo manifest

```bash
cat > my-first-plugin/.claude-plugin/plugin.json << 'EOF'
{
  "name": "my-first-plugin",
  "description": "A greeting plugin to learn the basics",
  "version": "1.0.0",
  "author": {
    "name": "Your Name"
  }
}
EOF
```

### Bước 3: Thêm Skill

```bash
mkdir -p my-first-plugin/skills/hello

cat > my-first-plugin/skills/hello/SKILL.md << 'EOF'
---
description: Greet the user with a personalized message
---

# Hello Skill

Greet the user named "$ARGUMENTS" warmly and ask how you can help them today.
Make the greeting personal and encouraging.
EOF
```

### Bước 4: Test plugin

```bash
# Load plugin tạm thời trong session
claude --plugin-dir ./my-first-plugin

# Trong session, thử:
/my-first-plugin:hello Alex

# Hoặc check skill hiện trong help:
/help
```

### Bước 5: Thêm Agent (Optional)

```bash
mkdir my-first-plugin/agents

cat > my-first-plugin/agents/security-reviewer.md << 'EOF'
---
name: security-reviewer
description: Specializes in security analysis and vulnerability detection
---

You are a security expert. When reviewing code, analyze for:
1. SQL injection, XSS, CSRF vulnerabilities
2. Authentication and authorization flaws
3. Sensitive data exposure
4. Insecure dependency usage
5. Hardcoded credentials or secrets

Be thorough but concise. Provide actionable recommendations.
EOF
```

### Bước 6: Thêm Hooks (Optional)

```bash
mkdir my-first-plugin/hooks

cat > my-first-plugin/hooks/hooks.json << 'EOF'
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "${CLAUDE_PLUGIN_ROOT}/scripts/format-code.sh"
          }
        ]
      }
    ]
  }
}
EOF

# Tạo script cho hook
mkdir my-first-plugin/scripts
cat > my-first-plugin/scripts/format-code.sh << 'EOF'
#!/bin/bash
# Auto-format code after Claude edits
file_path=$(jq -r '.tool_input.file_path' < /dev/stdin)
if [[ "$file_path" == *.ts ]] || [[ "$file_path" == *.js ]]; then
    npx prettier --write "$file_path" 2>/dev/null
fi
EOF
chmod +x my-first-plugin/scripts/format-code.sh
```

## 3. Tạo và phân phối Marketplace

### Bước 1: Tạo structure

```bash
mkdir -p my-marketplace/.claude-plugin
mkdir -p my-marketplace/plugins/my-plugin/.claude-plugin
mkdir -p my-marketplace/plugins/my-plugin/skills/hello
```

### Bước 2: Plugin manifest

```bash
cat > my-marketplace/plugins/my-plugin/.claude-plugin/plugin.json << 'EOF'
{
  "name": "my-plugin",
  "description": "My custom plugin",
  "version": "1.0.0"
}
EOF
```

### Bước 3: Plugin skill

```bash
cat > my-marketplace/plugins/my-plugin/skills/hello/SKILL.md << 'EOF'
---
description: A friendly greeting skill
disable-model-invocation: true
---
Greet the user warmly and ask how you can help today.
EOF
```

### Bước 4: Marketplace file

```bash
cat > my-marketplace/.claude-plugin/marketplace.json << 'EOF'
{
  "name": "my-plugins",
  "owner": {
    "name": "Your Name"
  },
  "plugins": [
    {
      "name": "my-plugin",
      "source": "./plugins/my-plugin",
      "description": "My custom plugin"
    }
  ]
}
EOF
```

### Bước 5: Test locally

```bash
# Trong Claude Code:
/plugin marketplace add ./my-marketplace
/plugin install my-plugin@my-plugins
/my-plugin:hello
```

### Bước 6: Distribute

```bash
# Push lên GitHub
cd my-marketplace
git init
git add .
git commit -m "Initial marketplace release"
git remote add origin https://github.com/your-org/claude-plugins.git
git push -u origin main

# Team members add:
/plugin marketplace add your-org/claude-plugins
```

### Bước 7: Cấu hình Team marketplace (via settings)

Thêm vào `.claude/settings.json` của project:

```json
{
  "extraKnownMarketplaces": {
    "company-tools": {
      "source": {
        "source": "github",
        "repo": "your-org/claude-plugins"
      }
    }
  },
  "enabledPlugins": {
    "code-formatter@company-tools": true,
    "security-scanner@company-tools": true
  }
}
```

## 4. Convert .claude/ Config → Plugin

### Migration Steps

```bash
# 1. Tạo plugin structure
mkdir -p my-plugin/.claude-plugin

# 2. Tạo manifest
cat > my-plugin/.claude-plugin/plugin.json << 'EOF'
{
  "name": "my-plugin",
  "description": "Migrated from standalone configuration",
  "version": "1.0.0"
}
EOF

# 3. Copy existing files
cp -r .claude/commands my-plugin/       # Commands
cp -r .claude/agents my-plugin/         # Agents (nếu có)
cp -r .claude/skills my-plugin/         # Skills (nếu có)

# 4. Migrate hooks
mkdir my-plugin/hooks
# Chuyển hooks từ .claude/settings.json → my-plugin/hooks/hooks.json
# Cấu trúc giữ nguyên, chỉ extract phần "hooks" ra file riêng

# 5. Test
claude --plugin-dir ./my-plugin
```

### Những thay đổi khi migrate

| Trước (`.claude/`) | Sau (Plugin) |
|---|---|
| `.claude/commands/` | `plugin-name/commands/` |
| Hooks trong `settings.json` | `hooks/hooks.json` riêng |
| Tên trực tiếp `/deploy` | Namespaced `/plugin-name:deploy` |
| Manual copy | `/plugin install` |
| Không versioning | `MAJOR.MINOR.PATCH` trong `plugin.json` |

## 5. Vận hành hàng ngày

### Plugin Management

```bash
# Xem plugin đã cài
/plugin                    # Mở interactive plugin manager

# Enable/Disable
/plugin disable formatter@my-marketplace
/plugin enable formatter@my-marketplace

# Uninstall
/plugin uninstall formatter@my-marketplace

# Update plugin
/plugin update formatter@my-marketplace

# Reload sau khi sửa code (dev mode)
/reload-plugins
```

### Marketplace Management

```bash
# Thêm marketplace
/plugin marketplace add anthropics/claude-code          # GitHub
/plugin marketplace add https://gitlab.com/co/plugins.git   # Git URL
/plugin marketplace add ./local-marketplace             # Local
/plugin marketplace add https://example.com/marketplace.json  # Remote URL

# Với branch/tag cụ thể
/plugin marketplace add https://gitlab.com/co/plugins.git#v1.0.0

# Browse plugins
/plugin                    # Tab "Discover"
```

### Debugging

```bash
# Start với debug mode
claude --debug

# Trong session
/debug

# Validate plugin
claude plugin validate
/plugin validate

# Check errors tab
/plugin → Errors tab

# Clear cache & reinstall
rm -rf ~/.claude/plugins/cache
# Restart Claude Code, reinstall plugins
```

## 6. Cheat Sheet

### CLI Commands

| Lệnh | Mô tả |
|---|---|
| `claude --plugin-dir ./path` | Load plugin tạm thời (dev) |
| `claude --plugin-dir ./p1 --plugin-dir ./p2` | Load nhiều plugins |
| `claude --debug` | Start với debug logging |
| `claude --version` | Kiểm tra version (cần ≥ 1.0.33) |
| `claude plugin install <name> [--scope <s>]` | Cài plugin (CLI) |
| `claude plugin uninstall <name> [--scope <s>]` | Gỡ plugin (CLI) |
| `claude plugin enable <name> [--scope <s>]` | Bật plugin |
| `claude plugin disable <name> [--scope <s>]` | Tắt plugin |
| `claude plugin update <name> [--scope <s>]` | Update plugin |
| `claude plugin validate` | Validate structure |

### Slash Commands (trong session)

| Command | Mô tả |
|---|---|
| `/plugin` | Interactive plugin manager |
| `/plugin install name@mkt` | Cài plugin |
| `/plugin uninstall name@mkt` | Gỡ plugin |
| `/plugin enable name@mkt` | Bật plugin |
| `/plugin disable name@mkt` | Tắt plugin |
| `/plugin update name@mkt` | Update plugin |
| `/plugin marketplace add <src>` | Thêm marketplace |

| `/help` | Xem tất cả commands/skills |
| `/debug` | Debug info |

| File | Location | Chức năng |
|---|---|---|

| Commands | `commands/<name>.md` | Legacy commands |
| Hooks | `hooks/hooks.json` | Hook configurations |
| MCP | `.mcp.json` | MCP server configs |
| LSP | `.lsp.json` | LSP server configs |

| File | Location | Chức năng |

## 7. Troubleshooting

### Plugin không load

| Triệu chứng | Kiểm tra | Fix |
|---|---|---|
| `/plugin` không nhận | `claude --version` < 1.0.33 | Update Claude Code |
| Plugin không hiện | Cấu trúc sai | Đảm bảo `commands/` nằm ở plugin root, **không** trong `.claude-plugin/` |
| Manifest error | JSON syntax | Dùng JSON validator, check commas |
| `name: Required` | Thiếu `name` field | Thêm `"name"` trong `plugin.json` |

### Hooks không chạy

| Triệu chứng | Kiểm tra | Fix |
|---|---|---|
| Hook im lặng | Script permission | `chmod +x script.sh` |
| Hook không trigger | Event name case | `PostToolUse` (PascalCase), không phải `postToolUse` |
| Tool không match | Matcher pattern | `"matcher": "Write\|Edit"` — kiểm tra regex |
| Path not found | Relative paths | Dùng `${CLAUDE_PLUGIN_ROOT}/scripts/...` |
| Shebang missing | Script header | Thêm `#!/bin/bash` hoặc `#!/usr/bin/env bash` |

### LSP Server không khởi động

| Triệu chứng | Kiểm tra | Fix |
|---|---|---|
| `Executable not found` | Binary chưa cài | Cài binary: `npm install -g typescript-language-server` |
| High memory usage | Language server nặng | `/plugin disable <name>`, dùng built-in search thay thế |
| False positives in monorepo | Workspace config | Không ảnh hưởng editing — có thể ignore |

### Marketplace issues

| Triệu chứng | Kiểm tra | Fix |
|---|---|---|
| Marketplace not loading | URL accessible? | Verify `.claude-plugin/marketplace.json` tồn tại ở path |
| Install failed | Source URL accessible? | Repos phải public hoặc có auth token |
| Files not found | Cache isolation | Không reference files ngoài plugin dir |
| Skills không hiện | Cache cũ | `rm -rf ~/.claude/plugins/cache`, restart, reinstall |
| Private repo fails | Auth | Set `GITHUB_TOKEN`, `GH_TOKEN` hoặc `gh auth login` |

## 8. Best Practices

### ✅ Gold Rules

1. **Luôn validate JSON** — `plugin.json`, `hooks.json`, `marketplace.json` phải valid JSON
2. **Dùng `${CLAUDE_PLUGIN_ROOT}`** — Không hardcode absolute paths trong hooks/scripts
3. **Semantic versioning** — Update `version` trong `plugin.json` trước mỗi release
4. **README.md** — Include hướng dẫn cài đặt và sử dụng
5. **Test local trước** — `claude --plugin-dir ./plugin` trước khi publish
6. **CHANGELOG.md** — Document thay đổi mỗi version
7. **Namespace rõ ràng** — Đặt tên plugin có ý nghĩa, kebab-case
8. **`chmod +x`** — Scripts phải executable, có shebang line

### ❌ Anti-patterns

1. **Đừng** reference files ngoài plugin directory — sẽ fail sau khi cached
2. **Đừng** dùng absolute paths trong hook commands — không portable
3. **Đừng** quên `name` field trong `plugin.json` — required, gây crash
4. **Đừng** dùng camelCase cho event names — phải PascalCase (`PostToolUse`)
5. **Đừng** bundle cả `plugin.json` manifest VÀ marketplace entry cùng specify components — gây conflict
6. **Đừng** publish plugin chưa test — luôn `claude --plugin-dir` trước
