# Architecture and Logic — Gemini CLI

## Mô hình kiến trúc tổng thể

## Data Flow chi tiết

### Flow chính: User Prompt → Response

```mermaid
sequenceDiagram
    participant U as User
    participant CLI as CLI (React/Ink)
    participant Core as Core Engine
    participant Prompt as Prompt Engine
    participant Router as Model Router
    participant API as Gemini API
    participant Tools as Tool Registry
    participant Sandbox as Sandbox

    U->>CLI: Nhập prompt
    CLI->>Core: Forward user message
    Core->>Prompt: Assemble full prompt

    Note over Prompt: Kết hợp:<br/>1. System prompt<br/>2. GEMINI.md context<br/>3. Conversation history<br/>4. User message<br/>5. Tool definitions

    Prompt-->>Core: Complete prompt
    Core->>Router: Route request
    Router->>API: Send to Gemini model

    loop Agentic Loop
        API-->>Core: Response (text hoặc tool_call)

        alt Text Response
            Core-->>CLI: Stream markdown
            CLI-->>U: Render output
        else Tool Call
            Core->>Tools: Dispatch tool call
            Tools->>Tools: Check confirmation policy

            alt Needs Confirmation
                Tools-->>CLI: Request approval
                CLI-->>U: Hiển thị tool call details
                U->>CLI: Approve/Reject
            end

            alt Shell Command
                Tools->>Sandbox: Execute in sandbox
                Sandbox-->>Tools: Output + exit code
            else File Operation
                Tools->>Tools: Read/Write/Edit file
            else MCP Tool
                Tools->>Tools: Forward to MCP server
            end

            Tools-->>Core: Tool result
            Core->>Router: Send result back to model
            Router->>API: Continue conversation
        end
    end
```

### Flow: MCP Server Integration

```mermaid
sequenceDiagram
    participant Model as Gemini Model
    participant Core as Core Engine
    participant Registry as Tool Registry
    participant MCPMgr as MCP Client Manager
    participant MCPClient as MCP Client
    participant Server as MCP Server Process

    Note over MCPMgr: Startup: Load từ<br/>~/.gemini/settings.json

    MCPMgr->>Server: Spawn process (stdio/sse)
    Server-->>MCPMgr: Initialize + list tools
    MCPMgr->>Registry: Register MCP tools

    Model->>Core: Tool call: @server/tool_name
    Core->>Registry: Lookup tool
    Registry->>MCPClient: Execute MCP tool
    MCPClient->>Server: Call tool via protocol
    Server-->>MCPClient: Tool result
    MCPClient-->>Registry: Forward result
    Registry-->>Core: Return to model
```

### 5. Sandbox Architecture

| Provider | Mechanism | Platform | Mô tả |
|---|---|---|---|
| **macOS Seatbelt** | `sandbox-exec` | macOS only | Native OS-level sandboxing |
| **Docker** | Container isolation | Cross-platform | Full container isolation |
| **Podman** | Container isolation | Cross-platform | Docker alternative, rootless |
| **None** | Không sandbox | Tất cả | Mặc định, cần `GEMINI_SANDBOX=false` |

```mermaid
flowchart TD
    ShellTool["Shell Tool nhận command"]
    Check{"GEMINI_SANDBOX?"}
    ShellTool --> Check

    Check -->|true/seatbelt| Seatbelt["macOS Seatbelt<br/>sandbox-exec wrapper"]
    Check -->|docker| Docker["Docker Container<br/>Mount workspace read-write"]
    Check -->|podman| Podman["Podman Container<br/>Rootless isolation"]
    Check -->|false| Direct["Direct Execution<br/>No isolation"]

    Seatbelt --> Result["Return stdout + stderr + exit code"]
    Docker --> Result
    Podman --> Result
    Direct --> Result
```

## Configuration / API

### Cấu hình chính — `~/.gemini/settings.json`

| Setting | Type | Default | Mô tả |
|---|---|---|---|
| `theme` | string | `"default"` | Terminal theme |
| `model` | string | auto | Model mặc định |
| `sandbox` | string | `"false"` | Sandbox provider |
| `mcpServers` | object | `{}` | MCP server configurations |
| `trustedDirectories` | array | `[]` | Folders cho phép chạy mà không confirm |
| `telemetry` | boolean | `true` | Cho phép telemetry |

## Error Handling / Recovery

| Vấn đề | Cơ chế xử lý |
|---|---|
| **API rate limit** | Retry with exponential backoff |
| **Network timeout** | Auto-retry, thông báo user |
| **Tool execution failure** | Return error message to model, model decides next step |
| **Sandbox crash** | Fallback to non-sandbox, warn user |
| **Auth token expired** | Auto-refresh (OAuth), prompt re-auth (API key) |
| **Large file read** | Truncate + thông báo, dùng JIT context |
| **MCP server crash** | Restart server, retry tool call |
| **Model hallucination** | Omission Placeholder Detector chặn lazy output |
| **Diff apply failure** | Diff utils retry, fallback to full write |

### Omission Placeholder Detector

Module `omissionPlaceholderDetector.ts` phát hiện khi model trả về "lazy" output chứa placeholder thay vì code thật (ví dụ: `// ... rest of the code`). Khi phát hiện, tool sẽ reject edit và yêu cầu model viết đầy đủ.

## Security

| Mechanism | Mô tả |
|---|---|
| **Confirmation Policy** | Tool modifying (write, edit, shell) yêu cầu user approve |
| **Sandboxing** | Shell commands chạy trong môi trường isolated |
| **Trusted Folders** | Whitelist folders cho phép auto-execute |
| **SECURITY.md** | Responsible disclosure policy |
| **Auth Isolation** | Tokens stored locally, không gửi tới third-party |
| **Modifiable Tool Check** | `modifiable-tool.ts` kiểm tra tool có modify filesystem không |
