# Playbook — Gemini CLI

## Cài đặt & Thiết lập

### Yêu cầu hệ thống

| Yêu cầu | Chi tiết |
|---|---|
| **Node.js** | ≥20.0.0 (recommended ~20.19.0 cho development) |
| **OS** | macOS, Linux, Windows |
| **RAM** | Tối thiểu 4GB |
| **Network** | Cần kết nối internet (gọi Gemini API) |

### Cài đặt nhanh

#### Option 1: npx (không cần cài)

```bash
npx @google/gemini-cli
```

#### Option 2: npm global

```bash
npm install -g @google/gemini-cli
```

#### Option 3: Homebrew (macOS/Linux)

```bash
brew install gemini-cli
```

#### Option 4: MacPorts (macOS)

```bash
sudo port install gemini-cli
```

#### Option 5: Anaconda (restricted environments)

```bash
# Tạo environment mới
conda create -y -n gemini_env -c conda-forge nodejs
conda activate gemini_env

# Cài Gemini CLI
npm install -g @google/gemini-cli
```

### Chọn release channel

```bash
# Stable (mặc định) — recommended
npm install -g @google/gemini-cli@latest

# Preview — thử tính năng mới sớm
npm install -g @google/gemini-cli@preview

# Nightly — bleeding edge
npm install -g @google/gemini-cli@nightly
```

### Thiết lập xác thực

#### Cách 1: Google OAuth (Recommended — Miễn phí)

```bash
# Chỉ cần chạy gemini và chọn "Sign in with Google"
gemini
# → Chọn OAuth flow → Browser mở tự động → Login → Done
```

#### Cách 2: API Key

```bash
# Lấy key tại https://aistudio.google.com/apikey
export GEMINI_API_KEY="YOUR_API_KEY"
gemini
```

#### Cách 3: Vertex AI (Enterprise)

```bash
export GOOGLE_API_KEY="YOUR_API_KEY"
export GOOGLE_GENAI_USE_VERTEXAI=true
gemini
```

#### Cách 3b: Vertex AI với Code Assist License

```bash
export GOOGLE_CLOUD_PROJECT="YOUR_PROJECT_ID"
gemini
# → Chọn "Sign in with Google"
```

### Thiết lập Sandboxing (Recommended)

```bash
# macOS — Seatbelt (built-in, không cần cài thêm)
echo "GEMINI_SANDBOX=true" >> ~/.env

# Linux/Windows — Docker
echo "GEMINI_SANDBOX=docker" >> ~/.env

# Hoặc dùng Podman
echo "GEMINI_SANDBOX=podman" >> ~/.env
```

## Day 1 Workflow

### Bắt đầu với project hiện có

```bash
# 1. cd vào project
cd ~/projects/my-app

# 2. (Tùy chọn) Tạo GEMINI.md để customize behavior
cat > GEMINI.md << 'EOF'
# Project Context
This is a Next.js 14 app with TypeScript, Prisma ORM, and TailwindCSS.

## Coding Conventions
- Use functional components with hooks
- Follow ESLint/Prettier config
- Write tests for all new features
- Use absolute imports from @/

## Do NOT
- Modify database schema without asking
- Install new dependencies without confirmation
EOF

# 3. Chạy Gemini CLI
gemini

# 4. Bắt đầu tương tác
> Explain the architecture of this project
> What are the main components and how do they relate?
```

### Bắt đầu project mới

```bash
# 1. Tạo folder mới
mkdir my-new-project && cd my-new-project

# 2. Chạy Gemini CLI
gemini

# 3. Describe project
> Create a REST API with Express and TypeScript that manages a todo list.
> Include authentication, rate limiting, and PostgreSQL with Prisma.

# 4. Gemini sẽ tạo files, cài dependencies, và setup project cho bạn
```

### Headless mode cho scripting

```bash
# Simple text response
gemini -p "Explain the architecture of this codebase"

# JSON output cho parsing
gemini -p "List all functions in src/" --output-format json

# Streaming JSON cho monitoring
gemini -p "Run tests and fix all failures" --output-format stream-json

# Với model cụ thể
gemini -m gemini-2.5-flash -p "Refactor this function for performance"
```


### MCP Server Integration

#### Setup MCP Servers

Tạo/sửa file `~/.gemini/settings.json`:

```json
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_TOKEN": "ghp_YOUR_TOKEN"
      }
    },
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/home/user/documents"]
    },
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres"],
      "env": {
        "DATABASE_URL": "postgresql://user:pass@localhost:5432/mydb"
      }
    }
  }
}
```

#### Sử dụng MCP Tools

```bash
gemini
> @github List my open pull requests
> @github Create an issue titled "Refactor auth module"
> @postgres Show me the schema of the users table
```

### GitHub Actions Integration

```yaml
# .github/workflows/gemini-review.yml
name: Gemini CLI Review
on:
  pull_request:
    types: [opened, synchronize]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: google-github-actions/run-gemini-cli@v1
        with:
          prompt: "Review this PR for code quality, security issues, and suggest improvements"
```

## Configuration chiến lược

### Project-level GEMINI.md

```markdown
# GEMINI.md — Đặt ở root project

## Project Identity
This is [Project Name], a [description].

## Tech Stack
- Runtime: Node.js 20
- Framework: Express 5
- Database: PostgreSQL + Prisma
- Testing: Vitest + Supertest

## Conventions
- Use ESM modules (import/export)
- Follow Conventional Commits
- All new code must have tests

## Architecture
- `src/routes/` — API endpoints
- `src/services/` — Business logic
- `src/repositories/` — Data access
- `src/middleware/` — Express middleware
```

### Global GEMINI.md

```bash
# ~/.gemini/GEMINI.md — Áp dụng cho TẤT CẢ projects
cat > ~/.gemini/GEMINI.md << 'EOF'
# Global Preferences
- Always use TypeScript
- Prefer functional programming patterns
- Write comprehensive error handling
- Include JSDoc comments for public APIs
EOF
```

### Custom Commands

Tạo file `.gemini/commands/review.toml`:

```toml
[command]
description = "Review code changes"

[command.prompt]
text = """
Review the following changes for:
1. Security vulnerabilities
2. Performance issues
3. Code quality
4. Test coverage gaps

Focus on: $input
"""
```

Sử dụng: `gemini -c "review the latest commit"`

## Cheat Sheet

### CLI Commands

| Lệnh | Mô tả |
|---|---|
| `gemini` | Khởi động interactive mode |
| `gemini -p "prompt"` | Non-interactive, chạy rồi exit |
| `gemini -m gemini-2.5-flash` | Chọn model cụ thể |
| `gemini --include-directories ../lib` | Thêm context directories |
| `gemini --output-format json` | Output JSON |
| `gemini --output-format stream-json` | Streaming JSON events |
| `gemini -c "command-name"` | Chạy custom command |

### Slash Commands (trong interactive mode)

| Command | Mô tả |
|---|---|
| `/help` | Hiển thị tất cả commands |
| `/chat` | Mở chat session mới |
| `/clear` | Xóa conversation history |
| `/save` | Lưu checkpoint hiện tại |
| `/restore` | Khôi phục từ checkpoint |
| `/model` | Đổi model |
| `/tools` | Liệt kê tools available |
| `/stats` | Usage statistics |
| `/bug` | Report bug |

### Keyboard Shortcuts

| Phím | Chức năng |
|---|---|
| `Enter` | Gửi prompt |
| `Ctrl+C` | Cancel current operation |
| `Ctrl+D` | Exit Gemini CLI |
| `↑` / `↓` | Navigate history |
| `Tab` | Autocomplete |

### Environment Variables

| Variable | Mô tả |
|---|---|
| `GEMINI_API_KEY` | API key từ AI Studio |
| `GOOGLE_API_KEY` | Google Cloud API key |
| `GOOGLE_CLOUD_PROJECT` | GCP project ID |
| `GOOGLE_GENAI_USE_VERTEXAI` | `true` để dùng Vertex AI |
| `GEMINI_SANDBOX` | `true`, `docker`, `podman`, hoặc `false` |
| `DEBUG` | `1` để bật debug mode |

## Troubleshooting

| Lỗi | Nguyên nhân | Fix |
|---|---|---|
| `EACCES: permission denied` | Không có quyền cài global | `sudo npm install -g @google/gemini-cli` hoặc fix npm permissions |
| `Node.js version not supported` | Node < 20 | Cài Node.js ≥20: `nvm install 20` |
| `Authentication failed` | Token expired hoặc sai key | `gemini` → chọn lại auth method |
| `Rate limit exceeded` | Vượt 60 req/min hoặc 1000 req/day | Đợi reset (1 phút hoặc 1 ngày), hoặc upgrade plan |
| `GEMINI_API_KEY is not set` | Chưa set env variable | `export GEMINI_API_KEY="your-key"` |
| `Sandbox error` | Docker/Podman chưa cài hoặc chưa chạy | `docker ps` để kiểm tra, hoặc `GEMINI_SANDBOX=false` |
| `MCP server not connecting` | Sai config hoặc server crash | Kiểm tra `~/.gemini/settings.json`, try `npx` command manual |
| `GEMINI.md not loaded` | File sai vị trí | Đặt ở root project, kiểm tra tên chính xác `GEMINI.md` |
| `0.0% success rate` | API key không hợp lệ hoặc model unavailable | Kiểm tra `GEMINI_API_KEY`, thử model khác |
| `Context too large` | Files quá lớn | Dùng `.gitignore` patterns, giảm `--include-directories` |
| `Tool execution timeout` | Shell command chạy quá lâu | Cancel bằng `Ctrl+C`, chạy command ngắn hơn |
| `Cannot find module` | Build lỗi (development) | `npm run clean && npm install && npm run build` |

## Best Practices

### ✅ Gold Rules

| Rule | Giải thích |
|---|---|
| **Dùng GEMINI.md** | Đặt trong mỗi project để customize agent behavior |
| **Enable Sandboxing** | Luôn bật sandbox khi agent chạy shell commands |
| **Dùng Plan Mode** | Cho complex tasks, để model plan trước khi execute |
| **Review tool calls** | Đọc kỹ trước khi approve write/edit/shell actions |
| **Checkpoint thường xuyên** | `/save` trước khi thay đổi lớn |
| **Small prompts** | Chia nhỏ tasks, prompt cụ thể hơn prompt mơ hồ |
| **Specify model** | Dùng `flash` cho tasks nhanh, `pro` cho complex reasoning |

### ❌ Anti-patterns

| Anti-pattern | Tại sao xấu | Thay thế |
|---|---|---|
| **Prompt quá mơ hồ** | "Fix my code" → model không biết fix gì | "Fix the null pointer in `getUserById` at line 42" |
| **Approve mọi thứ blind** | Có thể overwrite quan trọng | Đọc diff trước khi approve |
| **Không dùng GEMINI.md** | Agent không hiểu conventions | Tạo GEMINI.md với project context |
| **Bỏ qua sandbox** | Shell commands chạy trực tiếp trên system | `GEMINI_SANDBOX=true` hoặc `docker` |
| **Quá nhiều context** | Tốn tokens, giảm performance | Chỉ include directories cần thiết |
| **Không checkpoint** | Mất progress nếu có lỗi | `/save` thường xuyên |
| **Dùng nightly ở production** | Có thể có breaking bugs | Dùng `@latest` cho production work |

### Tips nâng cao

1. **MCP cho team workflow**: Setup shared MCP servers cho database queries, deployment, monitoring
2. **GitHub Actions automation**: Tự động review PRs, triage issues, generate changelogs
3. **Headless CI/CD**: Dùng `gemini -p` trong CI pipelines cho code analysis
4. **Multi-project**: Dùng global `~/.gemini/GEMINI.md` cho preferences chung, project-level cho specifics
5. **Token caching**: Enable token caching cho repeated queries trên cùng codebase

## Phát triển & Contribute

### Setup development environment

```bash
# Clone repo
git clone https://github.com/google-gemini/gemini-cli.git
cd gemini-cli

# Dùng đúng Node.js version
nvm use  # Reads .nvmrc → Node.js ~20.19.0

# Install dependencies
npm install

# Build tất cả
npm run build

# Chạy dev mode
npm run start

# Chạy tests
npm run test

# Full validation (trước khi submit PR)
npm run preflight
```
