# Gemini CLI vs Claude Code — Bảng so sánh tương đương

> Tài liệu này giúp developer đang dùng **Claude Code** nhanh chóng tìm lệnh/khả năng tương đương trong **Gemini CLI**, và ngược lại. Mỗi section đi kèm ghi chú về sự khác biệt.

## Tổng quan nhanh

| Tiêu chí | Gemini CLI | Claude Code |
|---|---|---|
| **Nhà phát triển** | Google | Anthropic |
| **Open-source** | ✅ Apache 2.0 | ❌ Closed-source |
| **Model** | Gemini 3 (Flash / Pro) | Claude 3.7 Sonnet |
| **Context window** | 1M tokens | 200K tokens (mở rộng được) |
| **Free tier** | 60 req/phút, 1,000 req/ngày | ❌ Trả phí (Max plan / API) |
| **Runtime** | Node.js ≥20 | Node.js |
| **Package** | `@google/gemini-cli` | `@anthropic-ai/claude-code` |
| **Binary** | `gemini` | `claude` |
| **License** | Apache 2.0 | Proprietary |

## 1. Khởi động & Session Management

| Chức năng | Claude Code | Gemini CLI | Ghi chú |
|---|---|---|---|
| **Khởi động interactive** | `claude` | `gemini` | ✅ Tương đương |
| **One-shot prompt** | `claude -p "prompt"` | `gemini -p "prompt"` | ✅ Tương đương |
| **Chọn model** | `claude --model claude-sonnet-4-6` | `gemini -m gemini-2.5-flash` | ✅ Tương đương |
| **Tiếp tục session cuối** | `claude --continue` | ❌ Không có | Gemini không lưu session |
| **Chọn session cũ** | `claude --resume` | ❌ Không có | — |
| **Fork session** | `claude --continue --fork-session` | ❌ Không có | — |
| **Thêm directory context** | `claude --add-dir ../lib` | `gemini --include-directories ../lib` | ✅ Tương đương |
| **Pipe input** | `cat file \| claude -p "analyze"` | `cat file \| gemini -p "analyze"` | ✅ Tương đương |
| **JSON output** | ❌ Không built-in | `gemini -p "..." --output-format json` | 🟢 Gemini mạnh hơn |
| **Streaming JSON** | ❌ Không built-in | `gemini -p "..." --output-format stream-json` | 🟢 Gemini mạnh hơn |

> **Nhận xét:** Claude Code mạnh hơn về **session management** — có thể continue, resume, fork sessions. Gemini CLI mạnh hơn về **structured output** cho scripting/automation.

## 3. Context Files — Project Instructions

Cả hai đều có hệ thống "context files" để customize agent behavior cho từng project, nhưng cơ chế khác nhau đáng kể.

| Chức năng | Claude Code | Gemini CLI | Ghi chú |
|---|---|---|---|
| **Project context** | `CLAUDE.md` hoặc `.claude/CLAUDE.md` | `GEMINI.md` | ✅ Concept tương đương |
| **Global context** | `~/.claude/CLAUDE.md` | `~/.gemini/GEMINI.md` | ✅ Tương đương |
| **Enterprise context** | `/etc/claude-code/CLAUDE.md` | ❌ Không có | 🔵 Claude-specific |
| **Subdirectory context** | `foo/CLAUDE.md` (auto-load) | ❌ Không có | 🔵 Claude flexible hơn |
| **Import files** | `@import README.md` | ❌ Không có | 🔵 Claude-specific |
| **Rules system** | `.claude/rules/*.md` | ❌ Không có | 🔵 Claude-specific |
| **Auto memory** | `MEMORY.md` — tự học patterns | ❌ Không có | 🔵 Claude tự học |
| **Custom commands** | `.claude/commands/` (Skills) | `.gemini/commands/*.toml` | ✅ Cả hai đều có, format khác |

### So sánh cấu trúc context files

```
# Claude Code                          # Gemini CLI
~/.claude/CLAUDE.md          ←→        ~/.gemini/GEMINI.md
./CLAUDE.md                  ←→        ./GEMINI.md
./.claude/CLAUDE.md          ←→        (cùng GEMINI.md ở root)
./.claude/rules/*.md         ←→        ❌ không có
./.claude/commands/          ←→        ./.gemini/commands/*.toml
~/.claude/projects/*/memory/ ←→        ❌ không có auto memory
```

> **Nhận xét:** Claude Code có hệ thống memory phong phú hơn nhiều — hierarchy 4 cấp, `@import`, auto memory, rules system. Gemini CLI đơn giản hơn — chỉ 2 cấp (global + project).

## 4. Built-in Tools

| Tool | Claude Code | Gemini CLI | Ghi chú |
|---|---|---|---|
| **Đọc file** | `Read` tool | `read-file` | ✅ Tương đương |
| **Đọc nhiều files** | Gọi `Read` nhiều lần | `read-many-files` (batch) | 🟢 Gemini hiệu quả hơn |
| **Sửa file** | `Edit` tool | `edit` tool (diff-based, 40KB logic) | ✅ Tương đương |
| **Tạo file** | `Create` tool | `write-file` tool | ✅ Tương đương |
| **Chạy shell** | `Bash` tool | `shell` tool | ✅ Tương đương |
| **Tìm file theo pattern** | `Search` (file pattern) | `glob` tool | ✅ Tương đương |
| **Tìm nội dung** | `Search` (content/regex) | `grep` + `ripGrep` (2 engines) | 🟢 Gemini có 2 engines |
| **List directory** | Qua `Bash(ls)` | `ls` tool (built-in, dedicated) | 🟢 Gemini có tool riêng |
| **Web fetch** | `WebFetch` tool | `web-fetch` tool | ✅ Tương đương |
| **Web search** | `WebSearch` (Brave/Google) | `web-search` (Google Search grounding) | ✅ Cả hai đều có |
| **Code intelligence** | Plugins (types, refs, definitions) | ❌ Không built-in | 🔵 Claude qua plugins |
| **Memory/save info** | Auto Memory (tự động) | `memoryTool` (thủ công) | Cơ chế khác nhau |
| **Plan mode** | `Shift+Tab` 2x → Plan mode | `enter-plan-mode` / `exit-plan-mode` | ✅ Cả hai đều có |
| **Hỏi user** | Tự hỏi trong agentic loop | `ask-user` tool (dedicated) | 🟢 Gemini có tool riêng |
| **Skills/commands** | Skill engine + `/command` | `activate-skill` tool | ✅ Cả hai đều có |
| **JIT context** | ❌ Không có | `jit-context` tool | 🟢 Gemini-specific |
| **TODO tracking** | ❌ Không built-in | `write-todos` tool | 🟢 Gemini-specific |
| **Internal docs** | ❌ Không có | `get-internal-docs` tool | 🟢 Gemini-specific |
| **Omission detection** | ❌ Không có | `omissionPlaceholderDetector` | 🟢 Gemini chặn lazy output |
| **Diff utilities** | ❌ Built-in (không rõ) | `diff-utils` (dedicated module) | 🟢 Gemini-specific |

> **Nhận xét:** Gemini CLI có **nhiều built-in tools chi tiết hơn** (20+ tools), còn Claude Code có **ít tools hơn nhưng bổ sung bởi plugins, subagents, và hooks**.

## 6. Safety & Permissions

| Chức năng | Claude Code | Gemini CLI | Ghi chú |
|---|---|---|---|
| **Confirm trước edit** | ✅ Default mode hỏi | ✅ Confirmation policy | ✅ Tương đương |
| **Auto-accept edits** | ✅ `Shift+Tab` → acceptEdits mode | ❌ Không có mode tương tự | 🔵 Claude linh hoạt hơn |
| **Plan-only mode** | ✅ `Shift+Tab` 2x → Plan mode | ✅ `enter-plan-mode` tool | ✅ Cả hai đều có |
| **Permission rules** | ✅ Allow/Ask/Deny per tool (granular) | ❌ Không có rule system | 🔵 Claude granular hơn |
| **dontAsk mode** | ✅ Bypass tất cả (cho CI/CD) | ❌ Không có | 🔵 Claude cho CI/CD |
| **Enterprise managed** | ✅ Managed settings (lock features) | ✅ Vertex AI + GCP policies | Cách tiếp cận khác |
| **Git checkpoints** | ✅ **Tự động** trước mỗi thay đổi | `/save` (thủ công) | 🔵 Claude tự động hơn |
| **Undo changes** | ✅ `Esc` key (instant) | `/restore` | ✅ Cả hai đều có |
| **Sandboxing** | ✅ Sandbox system | ✅ Seatbelt / Docker / Podman | 🟢 Gemini nhiều option hơn |
| **Trusted folders** | ❌ Không có | ✅ Whitelist folders auto-execute | 🟢 Gemini-specific |

## 10. Tóm tắt — Điểm mạnh riêng

### 🟢 Gemini CLI mạnh hơn ở

| Điểm mạnh | Chi tiết |
|---|---|
| **Free tier rộng rãi** | 1,000 req/ngày, không cần credit card |
| **1M token context** | Không cần `/compact`, đọc toàn bộ codebase lớn |
| **Structured output** | `--output-format json` và `stream-json` cho scripting |
| **Multi-sandbox** | Seatbelt + Docker + Podman — linh hoạt theo platform |
| **Cài đặt đa dạng** | npm, Homebrew, MacPorts, Conda, npx |
| **A2A server** | Agent-to-Agent protocol (experimental) |
| **SDK package** | Public SDK cho tích hợp programmatic |
| **Token caching** | Tối ưu token usage cho repeated queries |
| **Omission detection** | Chặn model viết lazy placeholder output |
| **Google Search grounding** | Real-time search built-in |
| **Open-source** | Apache 2.0 — fork, modify, contribute |

### 🔵 Claude Code mạnh hơn ở

| Điểm mạnh | Chi tiết |
|---|---|
| **Multi-interface** | Terminal, VS Code, JetBrains, Desktop, Web, Mobile, Slack |
| **Session management** | Continue, resume, fork sessions |
| **Auto memory** | Tự học patterns & preferences cross-sessions |
| **Memory hierarchy** | 4 cấp: Enterprise → User → Project → Subdirectory |
| **Granular permissions** | Allow/Ask/Deny rules per tool, managed settings |
| **Git checkpoints tự động** | Safety net không cần thao tác thủ công |
| **Subagents** | Delegate tasks song song cho specialized agents |
| **Hooks** | Event-driven automation (pre-commit, post-edit) |
| **Plugins & marketplace** | Code intelligence, type checking, refs |
| **`/compact` + `/context`** | Quản lý context window chủ động |
| **`/init` wizard** | Tạo context file có hướng dẫn |
| **Chrome extension** | Tương tác với browser context |

## Migration Quick Reference

### Từ Claude Code → Gemini CLI

```bash
# 1. Cài đặt
npm install -g @google/gemini-cli

# 2. Chuyển CLAUDE.md → GEMINI.md
cp CLAUDE.md GEMINI.md
# (Nội dung giữ nguyên — cả hai đều đọc Markdown instructions)

# 3. Chuyển global context
cp ~/.claude/CLAUDE.md ~/.gemini/GEMINI.md

# 4. Config MCP servers
# Từ: ~/.claude/settings.json → ~/.gemini/settings.json
# Format mcpServers tương tự

# 5. Thay đổi thói quen
# claude -p "prompt"  →  gemini -p "prompt"
# claude --continue   →  ❌ (bắt đầu session mới)
# /compact            →  ❌ (1M context, không cần)
# Esc (undo)          →  /restore
# Shift+Tab           →  ❌ (confirm từng tool call)
```

### Từ Gemini CLI → Claude Code

```bash
# 1. Cài đặt
npm install -g @anthropic-ai/claude-code

# 2. Chuyển GEMINI.md → CLAUDE.md
cp GEMINI.md CLAUDE.md

# 3. Thay đổi thói quen
# gemini -p "prompt"           →  claude -p "prompt"
# gemini -m model              →  claude --model model
# /save                        →  tự động (git checkpoint)
# /restore                     →  Esc (undo)
# --output-format json         →  ❌ (pipe output thủ công)
# gemini --include-directories →  claude --add-dir
```
