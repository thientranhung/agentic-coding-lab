## Extension Ecosystem — Chi tiết hooks

| Hook | Event | Chức năng | Cross-runtime |
|---|---|---|---|
| `gsd-statusline.js` | `Notification` | Model name, current task, context usage progress bar. Bridge file cho context-monitor | Claude Code, Gemini |
| `gsd-context-monitor.js` | `PostToolUse` / `AfterTool` | Inject `additionalContext` warning khi context thấp. WARNING @ 35%, CRITICAL @ 25%. GSD-aware messages | Claude Code, Gemini |

## Highlight

> GSD v1.26 **tăng đáng kể** nhờ: node repair operator (autonomous task recovery), `/gsd:autonomous` mode, MCP tool awareness, HANDOFF.json/WAITING.json (machine-readable signals), `/gsd:do` natural language routing, và cross-phase regression gates. **Agentic score 18/20** — gần tối ưu, chỉ thiếu full HOTL mode cho verify step (vẫn needs human by design). **DX 13/15** nhờ `/gsd:do` eliminates learning curve entirely.
