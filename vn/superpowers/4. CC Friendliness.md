## Highlight

> Superpowers v5.0.5 **tăng 78→81** nhờ: execution handoff (+1 Agentic — user chọn SDD vs inline), Gemini CLI native extension (+1 Extensions — 5 platforms), review loop optimization (+1 Cost — token savings 30-40%), và cross-platform DX improvements (+1 DX).
>
> Đáng chú ý: v5.0.5 restore execution choice (SDD no longer mandatory) là một **calibration move** — cho users flexibility thay vì dogmatic enforcement. Inline execution option cũng giảm token cost đáng kể cho simple features.
>
> **Agentic Architecture 18/20** — matched GSD. Strengths khác nhau: Superpowers = TDD Iron Law + skills composable; GSD = context engineering + node repair + PR automation.
